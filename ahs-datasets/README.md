# Alberta Health Data Atlas

Supporting reference for [Project 001](../README.md). Project 001 is the consulting demonstration; this atlas is the Chinese–English source used to design its synthetic NACRS-style and DAD-style records. It is not a second project and it does not contain the generated workbooks.

The atlas covers nine commonly used Alberta administrative health datasets and clinical information systems.

## Interactive site

[Open the Alberta Health Data Atlas](https://alberta-health-data-atlas.tigerdogai.chatgpt.site)

## Coverage

- DAD — Discharge Abstract Database
- NACRS — National Ambulatory Care Reporting System
- Practitioner Claims
- Provincial Laboratory Data
- PIN — Pharmaceutical Information Network
- Vital Statistics
- Provincial / Population Registry
- Sunrise Clinical Manager
- Connect Care / Epic

The interactive project includes Chinese–English language switching, DAD/NACRS/PIN deep dives, field-family guidance, linkage notes, cohort-design examples, access guidance, source links, and interpretation caveats.

## Responsible use

This is an independent educational resource and is not an official Alberta Health Services, University of Calgary, Government of Alberta, or CIHI publication. It contains no patient-level data and does not replace legal, ethics, custodian, or data-access advice.

Official data-dictionary workbooks are not copied into this repository. The interactive atlas directs readers to the original official sources.

## Integration note

The interactive React application remains on its existing deployment. This repository keeps only the overview used as Project 001’s data-design reference, without copying dependencies, caches, proprietary workbooks, or patient data.
