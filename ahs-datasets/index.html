Supporting reference for Project 001

Alberta Health Data Atlas

The bilingual reference used to design Project 001’s synthetic records. It describes nine Alberta administrative datasets and clinical systems—record grain, field families, linkage, access, and interpretation—without supplying patient-level values.

Project overview

From catalogue to research question.

In Project 001, this reference decides what a synthetic row can represent and which fields belong together. It explains how each real source is generated, what one record represents, which field groups are commonly available, how datasets can be linked, and where interpretation caveats matter. Official access notes stay linked to their original sources.

Educational, source-linked, and independent.

This is an independent educational resource, not an official Alberta Health Services, University of Calgary, Government of Alberta, or CIHI publication. It contains no patient-level data. Official workbooks are not copied into this repository; readers are directed to their original sources. The atlas does not replace legal, ethics, custodian, or data-access advice.
